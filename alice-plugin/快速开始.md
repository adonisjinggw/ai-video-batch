# 🌸 艾莉丝 (Alice) - 快速开始指南

## 5分钟快速上手

### 第一步：安装插件

1. 打开VSCode
2. 按 `F5` 启动扩展开发主机
3. 或在VSCode中打开这个文件夹，然后按 `F5`

### 第二步：配置AI服务（可视化界面，完全不用改代码！）

1. 按 `Ctrl+Shift+P` 打开命令面板
2. 输入 `艾莉丝: 配置AI服务`
3. 打开配置面板，就像这样：

   ![配置面板](https://via.placeholder.com/600x400?text=配置面板截图)

4. **选择预设模板**：点击上方的预设卡片（OpenAI、Claude、Ollama 或 自定义）
5. **填写API密钥**：在新添加的服务卡片中填写你的API密钥
6. **测试连接**：点击"测试连接"按钮确认配置正确
7. **保存配置**：点击右下角"保存配置"按钮

**就这么简单！不用改任何代码！** 🎉

### 第三步：开始使用

#### 方式1：启动助手对话

1. 按 `Ctrl+Shift+P` 打开命令面板
2. 输入 `艾莉丝: 启动助手`
3. 输入你的需求，例如：
   - "帮我写一个快速排序函数"
   - "解释一下这段代码"
   - "优化这个函数"

#### 方式2：代码审查

1. 选中一段代码
2. 按 `Ctrl+Shift+P` 打开命令面板
3. 输入 `艾莉丝: 代码审查`
4. 艾莉丝会帮你审查代码

#### 方式3：配置服务

1. 按 `Ctrl+Shift+P` 打开命令面板
2. 输入 `艾莉丝: 配置AI服务`
3. 直接跳转到设置页面

## 安全特性说明

艾莉丝有多重安全保护，不会乱改你的代码：

✅ **必须确认才修改** - 所有代码修改都需要你点击"批准修改"才会应用  
✅ **变更预览** - 应用前先看Diff预览，清楚知道改了什么  
✅ **限制修改范围** - 单次修改不超过文件的30%  
✅ **检测危险操作** - 不会让你执行 `rm -rf` 之类的危险命令  
✅ **保护敏感内容** - API密钥、导入语句等不会被乱改  

## 常见问题

### Q: 支持哪些AI服务？
A: 支持 OpenAI GPT系列、Claude、Ollama本地模型，以及任何自定义第三方API。

### Q: 如何添加更多AI服务？
A: 打开配置面板（`艾莉丝: 配置AI服务`），点击预设模板或"+ 添加服务"按钮，完全不用改代码！

### Q: 可以关闭安全模式吗？
A: 可以，设置 `alice.safetyMode` 为 `false`，但不建议这么做。

### Q: 如何查看艾莉丝的输出？
A: 打开 "输出" 面板（View → Output），选择 "艾莉丝 (Alice)"。

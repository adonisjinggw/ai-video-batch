🔧 创建自定义技能

📖 什么是自定义技能？

自定义技能就是一个提示词模板，你可以把常用的AI指令保存为技能，每次使用时只需填入不同的参数即可。

📝 核心概念：提示词模板

在模板中用 {{变量名}} 标记需要动态替换的内容。执行时系统会把 {{变量名}} 替换为你输入的实际值。
模板：请为{{topic}}写一篇{{style}}风格的文案 参数填入：topic=旅行 style=文艺 实际发送：请为旅行写一篇文艺风格的文案

⚙️ 参数定义说明

每个 {{变量名}} 都需要在「参数定义」中添加对应条目：
变量名 (key) 必须和模板中 {{...}} 里的名字一致
显示名称 用户看到的中文标签
类型 文本 / 多行文本 / 数字 / 选择
默认值 可选，预填的初始值

🎯 完整示例 1：小红书笔记生成器

技能名称：小红书笔记生成器 图标：📝 模板类型：文本生成 描述：一键生成小红书爆款笔记 提示词模板： 请为「{{topic}}」生成{{count}}条小红书风格的笔记文案。 要求： 1. 标题要有吸引力，善用emoji 2. 风格：{{style}} 3. 每条200-300字 4. 包含3-5个话题标签 参数定义： 变量名: topic 显示名称: 笔记主题 类型: 文本 默认值: (空) 变量名: count 显示名称: 生成条数 类型: 数字 默认值: 3 变量名: style 显示名称: 写作风格 类型: 文本 默认值: 活泼有趣

🎯 完整示例 2：AI绘图提示词翻译

技能名称：提示词翻译助手 图标：🎨 模板类型：文本生成 描述：把中文画面描述翻译为英文AI绘图提示词 提示词模板： 请把以下中文画面描述翻译为专业的AI绘图提示词（英文）， 要求用Stable Diffusion / Midjourney 风格的关键词描述， 包含画面内容、光影、构图、风格等维度。 中文描述：{{description}} 画风偏好：{{art_style}} 参数定义： 变量名: description 显示名称: 画面描述 类型: 多行 默认值: (空) 变量名: art_style 显示名称: 画风偏好 类型: 文本 默认值: 电影质感

🎯 完整示例 3：视频脚本生成

技能名称：短视频脚本生成 图标：🎬 模板类型：文本生成 描述：根据主题自动生成带分镜的短视频脚本 提示词模板： 请为主题「{{topic}}」生成一个{{duration}}秒的短视频脚本。 目标平台：{{platform}} 要求： 1. 包含画面描述、台词/旁白、背景音乐建议 2. 分镜头设计，标注每个镜头时长 3. 开头3秒必须有hook吸引观众 参数定义： 变量名: topic 显示名称: 视频主题 类型: 文本 默认值: (空) 变量名: duration 显示名称: 视频时长 类型: 数字 默认值: 60 变量名: platform 显示名称: 目标平台 类型: 文本 默认值: 抖音

💡 小技巧

• 提示词写得越具体，AI输出效果越好
• 可以用 📥 导入 按钮导入别人分享的技能JSON文件
• 创建好的技能可以点 📤 导出 分享给朋友
• 模板类型选「图片生成」会调用图片API，「文本生成」会调用文本API

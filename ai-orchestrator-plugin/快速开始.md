# 🌸 艾莉丝 (Alice) - 快速开始指南

## 5分钟快速上手

### 第一步：安装插件

1. 打开VSCode
2. 按 `F5` 启动扩展开发主机
3. 或在VSCode中打开这个文件夹，然后按 `F5`

### 第二步：配置AI服务

1. 按 `Ctrl+,` 打开设置
2. 搜索 "艾莉丝"
3. 点击 `Edit in settings.json`
4. 复制以下配置并填入你的API密钥：

```json
{
  "alice.aiServices": [
    {
      "id": "openai-gpt4",
      "name": "OpenAI GPT-4",
      "type": "openai",
      "apiKey": "sk-你的OpenAI密钥",
      "baseUrl": "https://api.openai.com",
      "model": "gpt-4",
      "capabilities": [
        "code_generation",
        "code_review",
        "code_optimization",
        "text_generation"
      ],
      "priority": 10
    },
    {
      "id": "claude-3",
      "name": "Claude 3 Opus",
      "type": "claude",
      "apiKey": "sk-ant-你的Claude密钥",
      "baseUrl": "https://api.anthropic.com",
      "model": "claude-3-opus-20240229",
      "capabilities": [
        "code_generation",
        "code_explanation",
        "documentation",
        "text_generation"
      ],
      "priority": 9
    }
  ],
  "alice.safetyMode": true
}
```

### 第三步：开始使用

#### 方式1：启动助手对话

1. 按 `Ctrl+Shift+P` 打开命令面板
2. 输入 `艾莉丝: 启动助手`
3. 输入你的需求，例如：
   - "帮我写一个快速排序函数"
   - "解释一下这段代码"
   - "优化这个函数"

#### 方式2：代码审查

1. 选中一段代码
2. 按 `Ctrl+Shift+P` 打开命令面板
3. 输入 `艾莉丝: 代码审查`
4. 艾莉丝会帮你审查代码

#### 方式3：配置服务

1. 按 `Ctrl+Shift+P` 打开命令面板
2. 输入 `艾莉丝: 配置AI服务`
3. 直接跳转到设置页面

## 安全特性说明

艾莉丝有多重安全保护，不会乱改你的代码：

✅ **必须确认才修改** - 所有代码修改都需要你点击"批准修改"才会应用  
✅ **变更预览** - 应用前先看Diff预览，清楚知道改了什么  
✅ **限制修改范围** - 单次修改不超过文件的30%  
✅ **检测危险操作** - 不会让你执行 `rm -rf` 之类的危险命令  
✅ **保护敏感内容** - API密钥、导入语句等不会被乱改  

## 常见问题

### Q: 支持哪些AI服务？
A: 支持 OpenAI GPT系列、Claude、Ollama本地模型，以及任何自定义第三方API。

### Q: 如何添加更多AI服务？
A: 在设置的 `alice.aiServices` 数组中添加新的服务配置即可。

### Q: 可以关闭安全模式吗？
A: 可以，设置 `alice.safetyMode` 为 `false`，但不建议这么做。

### Q: 如何查看艾莉丝的输出？
A: 打开 "输出" 面板（View → Output），选择 "艾莉丝 (Alice)"。

## 提示和技巧

1. **选择代码后提问** - 先选中代码再提问，艾莉丝会更准确
2. **具体描述需求** - 越具体的需求，艾莉丝的回答越好
3. **多轮对话** - 可以继续对话来 refine 结果
4. **查看历史** - 艾莉丝会记住之前的对话内容
